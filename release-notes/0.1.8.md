# Relaybase Worker 0.1.8

Pairs with desktop **0.1.10**.

## Highlights

- Stop automatic Email Routing repair cron that flooded ops logs every 15 minutes
- Fix false-negative Email Routing health checks on accounts with many zones or rules

## Changes

- Remove the routing-repair cron; record `routing_repair` in ops log only when an owner runs console repair
- Paginate Cloudflare zone and Email Routing rule list APIs so health checks see the full account
- Remove legacy broadcast and audience catalog routes and cron
- Reorganize `src/lib` into domain folders (auth, cloudflare, mail, ops, catalog, d1)
