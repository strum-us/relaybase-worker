# Relaybase Worker 0.1.13

Pairs with Relaybase app **0.2.0** / Desktop Launcher **1.0.0**.

## Highlights

- **Reply send**: `In-Reply-To` and `References` are normalized before send. If Cloudflare rejects those headers, the message is sent once without them.
- **Send errors stay JSON**: Mail send failures return 503, so the edge keeps the JSON body and the app can show the real error.

## Changes

- Accept only `<id@host>` threading tokens, drop broken tokens, and cap `References` at 100 ids and 2,048 bytes.
- Retry a header rejection once with threading headers removed. Other send errors are not retried.
- Log the send stage, path, header presence, reference count, and whether threading headers were dropped.
