# Relaybase Worker 0.1.1

Initial public release of the Relaybase routing Worker.

Deploy this Worker into **your** Cloudflare account. It sends and receives product email, stores mail in your R2 and D1, and exposes inbox, send, and API routes. Relaybase does not host your mail.

## What's included

- Send and receive on your domain (Cloudflare Email Sending and Routing)
- Mailbox storage on R2, list/search index on D1
- Owner setup and desktop connection
- Domain-scoped API keys and inbound webhooks
- Mobile companion routes (`/mobile/*`)
