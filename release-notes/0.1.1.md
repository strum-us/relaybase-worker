# Relaybase Worker 0.1.1

First public release.

## Highlights
- Cloudflare OAuth install — Worker, R2, and D1 in the customer's account
- Owner passtoken auth (`AUTH_PEPPER` + scoped sessions)
- Single D1 app baseline — today's schema in one migration

## Changes
- `POST /console/init-db` / `migrate-db` / `setup-admin` with pepper bootstrap or OAuth
- Mail index (`RELAYBASE_MAIL`), ops log (`RELAYBASE_LOGS`), mailbox R2 layout
- Optional Worker `CF_ACCOUNT_ID`; domain/DNS via `CF_API_TOKEN`
