# Relaybase Worker 0.1.6

Pairs with desktop **0.1.9**.

## Highlights
- Persist sidebar, UI, and draft state in D1 for web and desktop parity
- Advertise `DESKTOP_VERSION` on `/health` so mailbox-mode desktops do not auto-update past this Worker
- More accurate Cloudflare API token probes (pairs with desktop 0.1.9 install)

## Changes
- Add `account_state` D1 table and console/mail/mobile routes for cross-device persistence
- Expose `DESKTOP_VERSION` on `/health` for mailbox-mode desktop update gating
- Allow `relaybase.email` and `workers.dev` origins in CORS
- Fix `CF_API_TOKEN` probe to match dashboard token permissions
- Improve the CF API token probe when Zone Read cannot be proven reliably
