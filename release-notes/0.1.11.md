# Relaybase Worker 0.1.11

Pairs with Relaybase web **0.2.0** / desktop **0.1.10**.

## Highlights

- **Install downloads on R2**: Customer install manifest and ZIP publish to `downloads.relaybase.email` as well as GitHub Releases, avoiding GitHub unauthenticated rate limits during signup.
- **Clearer console address errors**: Creating or updating mail accounts returns `422`/`503` JSON instead of `502`, so Cloudflare does not replace API errors with an HTML error page.

## Changes

- Add R2 publish scripts and dual-publish flow in `publish:github`.
- Return `422` for Cloudflare token permission failures and `503` for transient routing failures on `POST`/`PATCH /console/addresses`.
