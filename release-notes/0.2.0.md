# Relaybase Worker 0.2.0

Your Worker now keeps its own Cloudflare connection and updates itself.

## Highlights

- **No Cloudflare API token.** The Worker keeps the Cloudflare sign-in you give the Relaybase app (an OAuth grant, stored encrypted) and uses it for domains, DNS, Email Routing and Email Sending. The `CF_API_TOKEN` secret is gone; an old one is removed on update.
- **Automatic updates.** New signed releases install themselves every 30 minutes (Settings › Worker can turn this off). You can also update, retry, or go back to the previous version from the app.
- **Reconnect Cloudflare** in Settings › Cloudflare hands the Worker a new connection without reinstalling.

## Upgrading

Workers from 0.1.x update once from the Relaybase app (Settings › Worker › Update & connect Cloudflare). That update asks you to sign in to Cloudflare one last time; later updates need no sign-in.
