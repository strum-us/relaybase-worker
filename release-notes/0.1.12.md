# Relaybase Worker 0.1.12

Pairs with Relaybase app **0.2.0** / Desktop Launcher **1.0.0**.

## Highlights

- **App version on `/health`**: Replaces the retired mailbox-mode `DESKTOP_VERSION` gate with `APP_VERSION`, reported as `appVersion`.
- **Desktop launcher downloads CORS**: The public install bucket allows the desktop webview origins (`http://localhost:32838` release, `http://localhost:32830` tauri dev) so the launcher can fetch the manifest and ZIP.

## Changes

- Rename Worker `[vars]` `DESKTOP_VERSION` → `APP_VERSION`; `/health` now returns `appVersion`.
- Packed install `wrangler.toml` also writes `APP_CLIENT_VERSION` and `DESKTOP_VERSION` with the same value so current and older app installers can still read the ceiling.
- Add `http://localhost:32838` (and keep `32830`) on `downloads-cors.json`. Apply with `pnpm run setup:downloads`.
