# Relaybase Worker 0.1.7

Pairs with desktop **0.1.9** (routing repair after Worker update ships in a future desktop patch; use Dashboard **Cloudflare** repair or wait for the 15-minute cron until then).

## Highlights

- Fix inbound silence after Worker script upload when Email Routing rules stay `enabled: true` but lose the Worker dispatch target (Cloudflare Activity Log: **Delivery failed**, no `ops_log` / R2 / inbox row).

## Changes

- Add `refreshAllWorkerRules` to re-PUT every worker-action Email Routing rule (not only `enabled: false`).
- Routing repair cron: refresh all domains every 15 minutes and record `routing_repair` in ops log.
- `POST /console/domains/routing/repair` uses full rule refresh; add `POST /console/domains/routing/repair-all`.
- Inbound `email()` handler: record failure to ops log via `waitUntil` so D1 write issues do not block the error path.
