# Relaybase Worker 0.1.2

## Highlights

- Stricter `CF_API_TOKEN` verification: probe Email Routing and DNS permissions, not just Zone Read.
- Structured `cf_token_permission_missing` errors when inbox routing fails due to API token permissions.

## Changes

- Add `cloudflare-probe` for connect-time token validation.
- Return permission hints for `GET /zones/{id}/email/routing` auth failures.
- Include `code` and `domain` on mailbox routing errors when Cloudflare rejects the token.
