# Relaybase Worker 0.1.2

## Highlights
- Stricter `CF_API_TOKEN` verification: probe Email Routing, DNS, Email Sending, and Edit permissions
- Detect Google Workspace MX conflicts when adding or listing domains
- Structured `cf_token_permission_missing` errors when inbox routing fails due to API token permissions

## Changes
- Add `cloudflare-probe` for connect-time token validation (read + Edit via POST)
- Probe Email Sending permissions and return detailed token errors
- Check MX conflicts on domain add and list
- Return permission hints for `GET /zones/{id}/email/routing` auth failures
- Include `code` and `domain` on mailbox routing errors when Cloudflare rejects the token
